## 文件职责

- app：页面组装、页面元信息、全局设计系统。
- components：头尾、Hero、插画场景与可替换角色、按钮、分类卡、作品卡、共享道具图形。
- data：站点名称/标题/GitHub/角色路径，六分类和明确占位作品。
- public/illustrations：真实存在的本地 SVG。
- docs：实施记录、检查结果和实际浏览器截图。

## 检查方式

使用 `npm run typecheck`、`npm run lint`、`npm run build`；浏览器检查 DOM、资源加载、锚点、按键和四种尺寸并截图。纯展示组件不增加镜像实现的单元测试。记录实际执行结果，不将预期当作通过。
